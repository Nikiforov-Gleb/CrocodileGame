# 🎮Правила игры

👤 Прежде чем приступить к игре, необходимо указать никнейм и выбрать комнату для игры. Комнаты отличаются языком отгадываемых слов.

🎨 Ведущий рисует загаданное слово на канвасе, которое отобразится у него на экране. Остальные игроки должны писать свои варианты в чат.

⏱️ На отгадывание одного слова дается одна минута. Если в течение минуты слово не разгадано, начинается новый раунд.

🔄 Ведущим становится первый пользователь, вошедший в комнату. Далее ведущим назначается игрок, угадавший слово. Если слово не отгадано в течение минуты, ведущим становится следующий по списку.

💬 Чтобы слово в чате было засчитанным, сообщение должно состоять только из одного загаданного слова, без учета регистра.

# ⚙️Функционал


Приложение состоит из трех роутов:

### Стартовая страница

Прежде чем приступить к игре, пользователю необходимо указать никнейм. Он будет сохранен в local storage. При следующем посещении никнейм установится автоматически из local storage.

Пользователь может выбрать комнату, в которой будет играть. Каждая комната отличается языком угадываемых слов.

Пользователь может перейти на страницу «Об игре» с правилами игры, нажав кнопку «Об игре».

Нажав кнопку «Начать игру», пользователь попадает на страницу игры с выбранным языком.

### Основная страница

**Канвас**: На канвасе может рисовать только ведущий. Ниже расположена кнопка «Очистить», ее может нажать только ведущий. Другие пользователи текущей комнаты видят все, что происходит на канвасе.

**Информационный блок**: Ведущий видит в данном блоке слово, которое необходимо объяснить. Все игроки видят таймер в информационном блоке.

**Чат**: Ведущий не может писать в чат. Остальные пользователи могут писать в чат сообщения и предполагаемое слово. Также в чате отображаются автоматические сообщения с информацией по состоянию игры (слово угадано и кем, время вышло, ведущий вышел из игры).

С основной страницы можно выйти на стартовую страницу, нажав кнопку «На главную», тем самым покинув комнату. Также можно перейти на страницу «Об игре», нажав кнопку «Об игре», не покидая при этом игру.

### Страница с правилами игры

На данной странице описаны правила игры. На нее можно попасть с любой страницы. Нажав кнопку «Назад», вернуться на предыдущую страницу.

# 🛠️Разработка

* Для получения случайного слова используется API Random Word API https://random-word-api.herokuapp.com/home

Параметры:

 `number=1` — одно слово

 `diff=1` — легкое слово

 `lang=en` — по умолчанию, или язык, который выбрал пользователь

Если API не доступен, слово будет выбрано из предустановленного массива слов.

* Приложение покрыто тестами более 70%.

* Основной функционал покрыт интеграционными тестами.
